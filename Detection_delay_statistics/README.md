Name of Quantlet: Detection_delay_statistics

Published in: Measuring Statistical Risk

Description: This Python notebook studies through simulation how quickly a change in the dependence parameter of a Clayton copula can be detected by a monitoring statistic. It measures the detection delay for different magnitudes of the parameter shift and additionally tracks a time-varying dependence parameter of a six-dimensional Clayton copula using rolling estimates of Kendall's tau.
