Published in: Measuring Statistical Risk

Description: This Python notebook estimates the tail dependence between Siemens and Volkswagen stock returns by fitting Gaussian, Student-t, Gumbel, Clayton and Frank copulas to their standardised log returns and computing the implied tail dependence coefficients, complemented by a nonparametric estimator.
